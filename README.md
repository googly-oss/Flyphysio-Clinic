# Flyphysio Clinic — GitHub Pages

## Files
- `index.html` — responsive clinic website
- `assets/` — supplied clinic logo/banner/front photo, doctor portrait, and four videos

## Publish on GitHub Pages
1. Create a repository (for example `flyphysio-clinic`).
2. Upload **all contents** of this folder, including `index.html` and the `assets` folder. Do not upload only the HTML.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Wait for GitHub Pages to finish and open the URL shown on the Pages settings screen. It usually looks like `https://USERNAME.github.io/REPOSITORY/`.

## Before sharing with the client
- Open the published URL on desktop and mobile.
- Test the WhatsApp enquiry form, call link, Google Maps link, and all videos.
- Confirm the exact Instagram profile URL and clinic hours with the clinic.
- Confirm the listed treatments and doctor credentials with the clinic before publication.
- The appointment form opens WhatsApp; it does not submit to a server.
